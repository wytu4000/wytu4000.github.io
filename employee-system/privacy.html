隱私政策

更新日期：2026 年 9 月 7 日

本政策說明「新買醉員工系統」與本公開說明頁的資料處理方式。管理及資料聯絡信箱為 wytu4000@gmail.com。

處理哪些資料、用途是什麼？

  • 員工身分：LINE 登入取得的使用者識別資料，與店內既有名冊中的員工編號、姓名、角色及啟用狀態，用於確認是否為已登錄員工及可操作範圍。
  • 登入安全：登入驗證資料、登入有效期限、撤銷狀態與安全版本，用於維持登入、拒絕到期或停權帳號，以及處理登出。
  • 內部業務資料：已啟用功能所需的員工管理與出勤資料；使用定位打卡並允許瀏覽器定位時，會取得經緯度、定位精確度與取得時間，用於門市範圍及出勤核對。排假升級啟用後，會處理本人提交的排假日期、事由、提交時間、審核者、處理說明及審核結果，並保留申請與審核歷程以查回結果及避免重複處理。請勿在事由欄填入與申請無關的敏感資料。

Google 資料與授權

Google 授權由系統管理者完成，用於核對授權帳號的基本身分、讀取指定員工名冊，以及存取已授權給本應用程式的 Drive／Sheets 檔案。後端也會執行指定 Apps Script，並在排假安全接線啟用後與登入安全服務通訊。

日常服務使用逐檔授權範圍，不要求存取管理者整個 Google Drive，不讀取 Gmail 郵件，也不要求員工登入 Google 或授權員工個人的雲端檔案。部署與來源維護所需的管理授權，與日常資料服務授權分開。

保存位置與升級狀態

既有員工名冊及內部營運資料使用管理者指定的 Google Drive／Sheets 與 Apps Script。現行私人員工系統的登入安全保存仍使用既有 Google 後端；本次升級規劃遷移至 Cloudflare D1，讓登入安全資料與營運資料分開，排假業務資料仍保存在指定 Google 檔案。

截至本政策更新日，D1 登入與排假升級仍在接線及驗收，尚未切換正式服務。此處不將尚未啟用的流程描述為已上線。正式切換時會同步更新本政策的實際狀態。

誰可以存取？

資料用於新買醉內部員工管理及必要的系統維護。員工依本人資格操作，具權限的主管與管理者依其管理範圍處理資料。Google、LINE、Cloudflare、OpenAI Sites 與 GitHub Pages 等網站代管服務會在提供相關服務時處理必要資料；不會將員工申請內容發布到這個公開 GitHub 網站。

瀏覽器與本公開頁

員工系統使用必要的登入 Cookie；部分操作會在瀏覽器保存查回所需的識別資訊，畫面狀態不代表後端已保存。本說明頁與隱私頁沒有資料輸入表單、登入程式、分析追蹤碼或廣告程式。

GitHub Pages 代管服務會記錄訪客 IP 位址等服務紀錄，詳見 GitHub 隱私聲明。同網域原有 PIN 登入頁使用自己的既有登入流程，會在瀏覽器 sessionStorage 保存姓名與 PIN；本次新增公開頁未更動該流程。

保存期間、更正與刪除

目前尚未訂定本系統全部資料類別的統一保存期限，也未完成排假歷史的自動刪除機制；不以登入有效期限代表申請資料已刪除。資料保存與刪除需求須依資料類型、實際業務需求及適用義務確認。

如需查詢、更正或提出刪除要求，請聯絡 wytu4000@gmail.com，說明要處理的資料；不要寄送密碼、PIN 或登入憑證。管理者核對身分、權限及需保留的資料範圍後處理。管理者也可從 Google 帳戶撤銷應用程式授權；撤銷會中止相應存取能力，但不等於已刪除既有業務紀錄。
